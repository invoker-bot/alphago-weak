Method

The candidate track starts from the current champion weights and keeps training on its own self-play samples. If a candidate is rejected, the same candidate continues training; it advances only when a paired color-swapped gate match reaches the threshold. The win rate is converted into an Elo delta. Random-bot games are not used as the main strength metric.

Relative komi is selected by same-generation champion mirror matches so that black's win rate is as close to 50% as the sampled grid allows. Candidate win rate therefore reflects model differences more than fixed-komi color bias.
